# Anti-Doomscroll

A calm, mobile-friendly pause page. When you catch yourself about to doomscroll, open this page, pick something better, and sit with a 10-minute timer.

## Use it

Open `index.html` in a browser, or host the file on [Netlify Drop](https://app.netlify.com/drop) / GitHub Pages.

Everything (choices, action log, stats) stays in your browser via `localStorage`. No accounts, no build step.
